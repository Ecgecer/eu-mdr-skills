pass it. PASS requires the response to flag:
(1) MDR Art. 7(c) — failing to inform of a likely risk: the copy omits the

    decisions the intended purpose explicitly carves out (Art. 7(b) and/or
    7(d) both acceptable).
The response must recognise that (c) is an OMISSION test and not dismiss the
copy as compliant because it contains no false statement.
FAIL if the response concludes there are no findings.
