Implementing rule 3.3: software which DRIVES a device or influences its use falls
within the SAME CLASS as that device. Rule 11 is not reached. The pump is Class III,
so the software is Class III.

PASS requires:
(1) The stated class is **III**.
(2) The route is via implementing rule **3.3**, identified by number or clearly
    described as "same class as the device it drives".
(3) It does NOT conclude via Rule 11. Mentioning Rule 11 to explain that 3.3 takes
    precedence and Rule 11 is therefore not reached is CORRECT and passes. Using a
    Rule 11 limb to reach the final class is a FAIL.

FAIL if the answer is IIa, IIb, or I. FAIL if it reaches its class through Rule 11
limbs rather than 3.3. Setting an infusion rate is the textbook "drives a device"
case, and skipping 3.3 is the most common classification error for software.
