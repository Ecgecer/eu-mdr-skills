## Correction, 2026-09-10, twice

An earlier version published **`no-disclaimer` as 1.00 / 0.67, delta +0.33**, and a mean
of +0.33. The 0.67 counted a run that failed with `Credit balance is too low` as a score
of zero. A billing failure is not a skill failure. The generator now excludes errored
runs from scoring and marks affected rows with ⚠.

That correction published **+0.22**, and that figure was wrong too — not miscounted this
time, just never regenerated. The table said "generated, do not hand-edit" and was then
pasted by hand, so it kept describing an older run than the one on disk. The real figure
from the stored runs is **+0.11**. The table is now spliced in by
`report-evals.py --write` and CI fails if it drifts, because "generated" turned out to
mean "generated once".

## `no-disclaimer` measures −0.67: the skill makes this case worse

This is the only negative delta in the repo, and it was published as +0.00 while the
stored runs said otherwise.

The baseline writes a finished scope statement in all three runs. With the skill, two of
three runs hand back a form:

> **Against:** [pattern set + name dictionary, with version and date — fill this in]

> **Against:** Our own pattern set and name dictionary — not an external standard.
> `[Need from you: pattern set / dictionary version + date, and which countries' national
> ID formats are covered]`

The pinning discipline is right — a scope statement that cites "the current schema" with
no version is the failure this skill exists to prevent. What is wrong is the shape of the
output. Asked for a scope statement, the user gets a template to complete.

Naming the gap in prose costs nothing and stays honest: "our own pattern set and name
dictionary, version not supplied" is a finished sentence that claims no authority it
cannot support. A bracket is an unfinished document.

This is the same defect measured in `device-claims`' Anchor 1, where a missing intended
purpose stopped the review instead of narrowing it. Twice now, a demand for information
has eaten the deliverable. That is a pattern worth watching for in every skill here.

## `readiness-claim` moved to +0.33

An earlier note here called this "the zero that is probably a grader defect", on the
reasoning that the grader had no condition rewarding the pinning discipline and so could

theory is retired rather than carried forward.

`unpinned-basis` at +0.67 is unaffected: the baseline produced a confident block on
