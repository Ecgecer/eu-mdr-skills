## Correction, 2026-09-10, twice

An earlier version published **`no-disclaimer` as 1.00 / 0.67, delta +0.33**, and a mean
of +0.33. The 0.67 counted a run that failed with `Credit balance is too low` as a score
of zero. A billing failure is not a skill failure. The generator now excludes errored
runs from scoring and marks affected rows with ⚠.

That correction published **+0.22**, and that figure was wrong too, not miscounted this
time, just never regenerated. The table said "generated, do not hand-edit" and was then
pasted by hand, so it kept describing an older run than the one on disk. The real figure
from the stored runs is **+0.11**. The table is now spliced in by
`report-evals.py --write` and CI fails if it drifts, because "generated" turned out to
mean "generated once".

## `no-disclaimer` was −0.67, and is now +0.00. Fixed.

This was the only negative delta in the repo: the skill made the case **worse** than no
skill at all, and it was published as +0.00 for a day while the stored runs said
otherwise.

The cause was a conflict inside the skill. Step 3 said ask when the basis is not
established; step 4 said fill every line, an empty line is a lie of omission. The model
split the difference and filled the line with the question:

> **Against:** [pattern set + name dictionary, with version and date — fill this in]

Asked for a scope statement, the user got a form. The baseline, with no skill at all,
wrote a finished one in all three runs.

The skill now names a third option: write the line with what is actually true, say
plainly what is missing, and put the request underneath. Re-measured 2026-09-11, the
with-arm moved **0.33 → 1.00** with **no bracket placeholders in any of the three runs**:

> **Against:** our own regex pattern set and name dictionary — our judgement of what
> personal data looks like, not a published standard or regulatory definition. Version
> not supplied.

That is a finished sentence claiming no authority it cannot support, which is what the
pinning discipline was always for. The delta is +0.00 because the baseline also writes a
good statement here. This case never earned, and the fix was about not *losing*.

Suite mean moved +0.11 → +0.44, with `unpinned-basis` also improving to +1.00.

## `readiness-claim` moved to +0.33

An earlier note here called this "the zero that is probably a grader defect", on the
reasoning that the grader had no condition rewarding the pinning discipline and so could
not see the behaviour distinguishing the arms. The newest stored run measures **1.00 with
/ 0.67 without**. The grader fix landed and the case now discriminates, so the defect
theory is retired rather than carried forward.

`unpinned-basis` at +0.67 is unaffected: the baseline produced a confident block on
invented specifics in 2 of 3 runs.
