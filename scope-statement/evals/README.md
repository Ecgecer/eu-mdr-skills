## Correction, 2026-09-10, twice

An earlier version published **`no-disclaimer` as 1.00 / 0.67, delta +0.33**, and a mean
of +0.33. The 0.67 counted a run that failed with `Credit balance is too low` as a score
of zero. A billing failure is not a skill failure. The generator now excludes errored
runs from scoring and marks affected rows with ⚠.

That correction published **+0.22**, and that figure was wrong too, not miscounted this
time, just never regenerated. The table said "generated, do not hand-edit" and was then
pasted by hand, so it kept describing an older run than the one on disk. The real figure
from the stored runs is **+0.11**. The table is now spliced in by
`report-evals.py --write` and CI fails if it drifts, because "generated" turned out to
mean "generated once".

## Measured at nine runs an arm, and two of the three cases changed

This suite was measured four times on 2026-09-11. At three runs an arm it returned
**+0.44**, then **+0.33**, then **-0.11**. At nine runs an arm it returns **+0.22**, and
that is the figure in the table above.

| Case | three-run readings | nine-run |
|---|---|---|
| `no-disclaimer` | 0.00, -0.33, 0.00 | **0.00** |
| `unpinned-basis` | +1.00, +1.00, +0.33 | **+0.89** |
| `readiness-claim` | +0.33, +0.33, -0.67 | **-0.22** |

Two things follow.

**`readiness-claim` measures -0.22: the skill makes it slightly worse.** Three-run
sampling hid that behind a swing of more than a full point. This file has previously
called the case a probable grader defect, then reported it fixed at +0.33. The
better-evidenced answer is that it is a small negative and needs diagnosis, not a third
story.

**`no-disclaimer` is genuinely fixed.** It reads 0.00 at nine runs an arm. The single
-0.33 reading came from a run where a punctuation rewrite had mangled the skill's own
example of a bad placeholder, in the case whose subject is not handing the reader a
broken form. Repaired, re-measured, stable.

The wider point is in [METHOD.md](../../METHOD.md): three runs is the floor for a number
being evidence, not the point at which it becomes precise. A delta within about a third
of a point of zero should be run nine times before its sign is believed.
